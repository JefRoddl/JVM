## Site JVM
> Página desenvolvida para a empresa JVM Log, especializada na terceirização de serviços de mão de obra logística.

## SUMÁRIO
- Este projeto foi desenvolvido para melhorar a presença online da empresa JVM Log, destacando seus serviços de carga e descarga de caminhões, movimentação de pallets e aplicação de stretch em pallets.
- O site oferece uma navegação simples e direta, permitindo que os visitantes conheçam os serviços oferecidos e entrem em contato de forma eficiente.

## Tecnologias Utilizadas
- React: Criação da interface de usuário dinâmica.
- CSS: Estilização do site com design moderno e responsivo.
- JavaScript: Interatividade e funcionalidades adicionais.
- Vite: Ferramenta para otimizar o desenvolvimento do projeto.

## Funcionalidades
-  Navegação simples e intuitiva por seções.
-  Descrição detalhada dos serviços oferecidos: carga e descarga, movimentação de pallets e aplicação de stretch em pallets.
- Formulário de contato direto para solicitações e orçamentos.
- Design responsivo adaptado para diferentes dispositivos.
